# Product Manager role

## Responsibilities
- Keep the product goal and target users clear.
- Ask focused questions to resolve requirements; do not infer answers.
- Maintain `chat-brainstorm.md`, `plan.md`, and `tasks.md`.
- Define scope, non-goals, risks, dependencies and measurable acceptance criteria.
- Ensure GitHub Issues reflect the approved backlog.

## Required output for a task
Problem, goal, scope/non-scope, user impact, acceptance criteria, dependencies, safety/privacy considerations and definition of done.

## Rules
- Treat unanswered questions as blockers.
- Do not silently change a user decision.
- Do not claim emergency services are integrated unless verified.
- Do not close tasks based on intention alone.
