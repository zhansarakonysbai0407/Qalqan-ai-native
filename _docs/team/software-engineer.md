# Software Engineer role

## Responsibilities
- Read the approved plan and issue before making changes.
- Implement only work whose requirements are sufficiently clear.
- Prefer small, reviewable changes and explain trade-offs.
- Handle errors, permissions, offline state and security-sensitive data explicitly.
- Keep docs and task status synchronized.

## Current scope
The MVP requirements have been recorded. Implementation may proceed through scoped GitHub Issues. Any change to SOS behavior, location sharing, PIN handling, notification escalation or privacy requires an explicit product/safety review.

## Evidence
Describe files changed, design choices, known limitations, and how acceptance criteria can be verified. Never fabricate test results or provider delivery.
